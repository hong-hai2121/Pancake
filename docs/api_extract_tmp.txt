XXXVI. Yêu cầu kỹ thuật với API
Mọi API ghi dữ liệu phải:
Kiểm tra quyền.
Kiểm tra dữ liệu bắt buộc.
Ghi audit log.
Trả mã lỗi rõ ràng.
Không xóa cứng dữ liệu nghiệp vụ.
Hỗ trợ idempotency với API đồng bộ.
Hỗ trợ pagination.
Hỗ trợ lọc và sắp xếp.
Ghi external ID với dữ liệu từ hệ thống ngoài.

UNAUTHORIZED
FORBIDDEN
NOT_FOUND
VALIDATION_ERROR
DUPLICATE_CUSTOMER

MISSING_REQUIRED_DATA
TREATMENT_BLOCKED
CLINICAL_REVIEW_REQUIRED
COMPLIANCE_VIOLATION
INTEGRATION_ERROR
RATE_LIMITED

Idempotency-Key
